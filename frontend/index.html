H-A-R-E Framework

Build, run, and evolve autonomous workflows with H-A-R-E.

H-A-R-E is a modular agent system for orchestration, memory, skills, and tool-driven execution. Start quickly, wire in your own integrations, and iterate toward production-grade agent behavior.

Setup Guide

Follow these steps to run H-A-R-E locally.

  1. Clone the repository and enter the project directory.
  2. Install dependencies with your package manager.
  3. Create your environment configuration for keys and tokens.
  4. Start the orchestrator to run your agent workflow.
git clone <your-repo-url>
cd hare
pnpm install
cp .env.example .env
pnpm start

Usage Overview

A quick map of how to work with the project after setup.

Core Runtime

Use the orchestrator and heartbeat modules to drive recurring or event-based agent tasks.

Skills

Implement feature-specific logic in the skills/ directory (email, scraping, wallet, scheduling, and more).

Tools & Gateways

Connect external APIs and channels through tools/ and gateways/ modules.

Testing

Run project tests and script checks while iterating on new skills and integrations.

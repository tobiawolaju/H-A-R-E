05 // Usage Guide

Run HARE

  1. Install dependencies with pnpm install from the hare/ workspace.
  2. Set runtime secrets in .env, including Gemini, GitHub, and gateway tokens for the surfaces you enable.
  3. Start the headless agent with pnpm start and watch gateway logs for connection status.
  4. Add or tune skills in skills/, then restart HARE so the orchestrator can load the new tool surface.
